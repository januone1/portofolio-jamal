# Jamal Setiadi — Portfolio Website

A responsive, dark-modern personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

## Personalize before publishing
- In `script.js`, replace `your.email@example.com` with your real email.
- Replace the LinkedIn URL with your real profile URL.
- In `index.html`, update the experience section with your official employer/vendor name, exact job title, and employment dates.
- Verify the experience duration and every skill/tool listed. Remove anything you have not used.
- Add only accurate, non-confidential project examples and measurable outcomes you can substantiate.

## Publish
Upload `index.html`, `style.css`, and `script.js` to a static hosting provider (for example GitHub Pages, Netlify, or your own web hosting). Keep all three files in the same directory.
